# Sentinel CV Assurance

Sentinel is an offline, evidence-producing prototype for SIH Problem Statement 26228. It
assesses classification datasets, model weights, inference provenance, and distribution
shift before producing a transparent governance disposition.

The implementation is contract-first and targets Python 3.10 on Windows 10/11 x86-64.
No frontend, service, database, or project-owned IPC is used in Phase 2.

## Development status

Implementation is proceeding in independently committed phases. See `docs/phase2` for the
governing PRD, TRD, schemas, orchestration flow, and sub-48-hour implementation plan.
