# Contributing to VisiOps

We welcome contributions from the community to make VisiOps the premier Model Forensics platform.

## How to Contribute
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-feature`).
3. Make your changes and add tests.
4. Run tests using `pytest tests/`.
5. Commit your changes (`git commit -m 'Add amazing feature'`).
6. Push to the branch (`git push origin feature/amazing-feature`).
7. Open a Pull Request.

## Code Style
Please adhere to PEP 8. We use `black` for formatting and `flake8` for linting.
